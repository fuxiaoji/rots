# AI-WIN-01 盟军胜局回放

这里保存冻结策略 `a35a557` 在固定日本 AI5 对手下的六局开发评测胜局。五局 1942 剧本胜局的种子是 `20261014`、`20261015`、`20261017`、`20261022`、`20261035`；前三局通过原子弹条件、后两局通过封锁获胜。另存一局 1943 剧本种子 `20261011` 的原子弹胜局，与本地观战页展示的对局相同。它们均属于**开发集**，不应当作独立留出评估；完整胜率结论见 [`research/ai-win-01/final-evaluation.md`](../../research/ai-win-01/final-evaluation.md)。

每个 `.replay.json.gz` 是完整原始动作回放的无损 gzip 压缩，包含种子、剧本、双方实际生效配置、规则版本、动作和决策日志。`bundles/` 保存回放所用的两个无损压缩的确定性规则包；`index.json` 记录压缩文件、原始回放、规则包和终局状态的 SHA-256。为避免把临时评测目录的约 300 MB 原始 JSON 加入仓库，归档采用 gzip；解压后可以直接查看 JSON。

在仓库根目录运行以下命令逐步重演并核对全部六局的自然胜利结果：

```sh
node tools/verify-ai-win-archive.js
```

也可以只验其中一局，例如 `node tools/verify-ai-win-archive.js 20261011`。回放所用的日本旧策略需要决策日志辅助恢复进程缓存，校验工具会使用归档内的精确版本规则包；不能把动作序列直接套到其它规则版本。RTT 对局页面需要 RTT 平台服务端及其数据库，单凭这些压缩文件不会自动出现在 RTT 大厅。
