# AI-WIN-02：两剧本开发胜局

这里归档增强盟军对固定日本 AI5 的九局**开发集**自然胜利。1942 剧本六局中，`20261204` 为封锁胜，其余五局为原子弹胜；1943 剧本三局中，`20261210` 为封锁胜，`20261214` 和 `20261221` 为原子弹胜。两个剧本各评测 32 局，胜率分别为 6/32 与 3/32，均远低于用户要求的 13/32 胜（40.625%）；这些录像不能作为独立留出评测证据。

`20261210` 的完整动作回放还记录到盟军地面部队在第 9 回合进入本州 3606、3706 格，第 10 回合进入 3705 格，最终于第 12 回合完成连续三个国势阶段的封锁胜利。这说明前沿集结和本州推进链在真实对局中可以执行，但此局胜因是封锁，不能称为本州全占胜。

每份 `.replay.json.gz` 是完整动作回放的无损压缩。`bundles/` 含精确规则包；`index.json` 绑定压缩回放、原始回放、规则包和终局状态的 SHA-256。运行以下命令可解包并逐动作重演，核对胜方、胜因与最终状态哈希：

```sh
node tools/verify-ai-win-archive.js --archive ai-win-02
```

单局可在命令尾加种子，如 `20261210`。旧日本 AI5 使用进程缓存，重新计算出的建议动作有时与原录像不同；核验器单列这种漂移，仍逐步检查录像动作的合法性，并要求完整最终状态哈希一致。归档不自动导入 RTT 大厅；大厅仍需要平台服务端和数据库。开发评测口径与未达标说明见 `research/ai-win-02/development-results.md`。
