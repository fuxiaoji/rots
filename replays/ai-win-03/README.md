# AI-WIN-03：v21 开发胜局

这里仅归档 v21 固定开发评测中通过完整合法动作回放的盟军自然胜局。每个剧本的胜率分母仍是全部32个预注册样本，失败不会从分母删除；胜局目录本身不构成胜率或独立泛化证据。完整统计及未达标情况见 [开发记录](../../research/ai-win-03/development-results.md)。

这些对局运行于精确冻结包 `82a79baa7413584f008ed9748e23e1f4135ada2cd4a72ae62c188adbd6029b09`，固定日本AI5为 `df4afef8e7705a960e05a4de99443d9663f32cc9c76632a65e4a538044266e43`。后来上传的AI／LLM整合包不是本批对局的执行来源，不能混算版本。

`index.json`绑定原始回放、无损压缩档、规则包和完整终局的SHA-256。压缩后的文件逐字节还原原始已核验回放，规则包也按原哈希校对。可在独立机器离线重演：

```sh
node tools/verify-ai-win-archive.js --archive ai-win-03
```

命令末尾可加种子；同一种子若出现在两个剧本，会核验全部匹配对局。验证器逐步检查合法动作、胜方、胜因、动作数及完整终局哈希。旧日本AI5的策略预热与建议漂移单独记录，不豁免终局一致性。本目录不包含私有LLM存档或凭据，也不会自动导入RTT大厅。
