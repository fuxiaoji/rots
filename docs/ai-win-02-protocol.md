# AI-WIN-02 本州登陆与胜率验证协议

固定规则版本 `official-16.2`，日本对手使用 AI-WIN-01 冻结的 `erasmus-v2-opt-v5` 规则包。盟军候选为本分支的 `erasmus-campaign`；AI-WIN-01 冻结版作为旧增强策略参照，不改写其对局与录像。

两个完整剧本分开评测。开发种子各为 `20261201–20261232`；策略、规则包、实际配置和执行上限冻结之后，留出种子各为 `20261301–20261332`。同一个种子配对比较；旧留出种子 `20261101–20261132` 只用于诊断，绝不复用为本轮独立验证。使用 `EOTS_EVAL_TASK=AI-WIN-02 node tests/campaign-evaluate.js` 固定上述范围。

用户目标为**每个剧本至少 13/32 局**（40.625%）经完整动作回放核验的合法自然盟军胜利。报告每臂胜率和 Wilson 95% 区间、配对差异、胜因（本州七格、封锁、原子弹、HQ）、提前条约败、PoW 达标率、首次有效前沿编队及可执行本州登陆时机。无效局与未核验胜局仍占预注册分母，不能算胜。每局绑定规则包、代码哈希、实际配置、种子、结束原因和最终状态哈希；每个胜局另存完整回放核验证据。

本州路线必须先形成同港、同军种、具备 ASP 和合法启动范围的地面及护航力量。每次登陆使用引擎移动查询与公开反应估算，且战役计划不得绕过当前 PoW 存活义务。策略改动只能改变盟军行动选择，不修改地图、判胜、补给、战斗或隐藏信息边界。运行时模型请求目标为 0。开发批次可用于调试；冻结留出批次只运行一次，若低于目标则如实记录并另启新任务/新种子继续优化。
