# LLM战役操作简述 CW-LLM-01

2026-10-06。下列是来源规则和现有接口的简述，不是新规则或FSM策略。每个实际动作仍须通过当前合法候选。

## 国家征服

中文V3.2 PDF35–36页 §§13.22/13.32/13.42/13.52，机械转写为normalized/eots-v3.2-zh-rules/chapters/13-national-status.md。菲律宾要求2813/2915；马来亚2014/2015；东印度2019/1813/1916/2017/2415/2616/2517/2220；缅甸2008/2106/2206/2305。地图数字是印刷mapId，执行引用必须用对应engineHex。

scenario.nations提供实际公开控制与正式投降回合。当前引擎国家检查按要求格不存在敌方控制判定，在国家状态段置投降标记；尚未结算的控制进度不是正式投降。已投降国家也可能解放，征服目标须同一时点四者都正式投降。

地面部队通过合法陆进/两栖形成控制，海空单独攻击不等于占领。先查卡牌/HQ启动范围与预算，规划地面、同港护航、格外空海支援；同港编组才共同移动，军种ISR、ASP、补给与堆叠由引擎查询限制。OC只声明一个战斗格；军事事件允许的声明数量和HQ/单位限制随事件，完整牌文缺失时不能靠名称想象特效。

PDF23–24页 §8.45.A：师及更小部队通常1ASP；军/集团军每军力级1ASP，满军力通常2ASP、损军力1ASP（日本韩国军例外每级2ASP）。每回合已用ASP不能再次用；反应最多1ASP。单位currentBaseASP只是当前军力面的基础需求，建制运输/驳船/事件等例外及整个编组共享费用仍按真实查询，不把基础值当完整费用。

缅甸可在解决菲律宾、马来亚时同步陆路推进；东印度的婆罗洲/苏门答腊与Java任务要分别安排，允许使用合法未命名中间陆格。集中和HQ前推须为下一张实际己牌可启动的部队服务。兵力不足可推迟一次攻势，不要重复激活—取消或无目标舰队出动。

## 战役胜利

中文V3.2 PDF41–42页 §16.1–16.3。PW0是日本胜，盟军必须保护PW和PoW；日本可以促成PW下降，不能把保持PW>0误写成日本通常胜利要求。本次日本四国目标另要求在自然终局前完成四国，提前PW赢棋而未征服四国不算实验成功。

盟军需按当前scenario.victory的本土控制、资源封锁与原子弹状态安排真实胜路，不把“接近基地”当自然胜利；南太平洋VP条件不适用于大战役。

## 战斗足够与损失阈值

中文V3.2 PDF29–30页 §§9.41–9.44。地面战同步结算，地面CF乘战果倍率（向上取整）得到打击值；修正后D10≤2为×0.5、3–6为×1、7–8为×1.5、9+为×2。伤害须达到单位LF才能造成一步；剩余不能分配的打击值丢弃，满军力单位先全部减损再消灭减损单位。两栖攻击者承受地面伤害时LF减半向上取整。双方仍有地面幸存者时损失更多步的一方败，平手守方胜；双方全灭守方维持控制，进攻方必须有幸存地面才能夺占。不能凭CF高于敌CF就说足够。

进攻地形DRM：丛林−1、混合−2、山地−3。海空战后己方独有战斗格海军可给进攻地面+2，己方独有参战航空/航母可给+2；各项须真实投入并幸存，不能只写支援计划。已有敌方地面/HQ的两栖登陆给守方+3。事件及装甲等仍按实际规则；这些简述不覆盖例外。PDF28–29页 §9.3：登陆前若海空战失败，两栖地面不能参加地面战；无支援的弱登陆有被反应阻断的风险。

例如9CF在最低倍率只造成5打击值，不能对LF6守军造成一步；若双方零损失仍是守方胜。可集中更多地面或投入实际海空优势，但应同时估计敌方反应，不把任何方案称必胜。taskFacts.groundArithmetic只做模型列出地面部队的倍率算术，尚未证明它们全部可达/已启动/可参战。

## 执行与记忆

每次只选当前candidateId，不写任意动作或__ai。移动窗先选择单位编组，再选方式，最后实际路径；结束激活不会自动移动。declaring/committing/support窗口按实际候选投入战斗；PBM不能再发动本次攻势。done是主动结束当前窗口，应说明任务已执行还是放弃。

程序observation及recent维护地点、计数、预算与国家状态，模型notes仅存判断/意图，不重抄易变事实。每个任务要具体到目标、地面/护航/支援、下一步；unknown查询不可当非法或已可行。合法路径不保证胜战，不使用敵手手牌、牌库或未来随机数。
