# 游戏主循环理解

> 本文是面向引擎设计的初步理解，不代替逐条规则。来源以 `docs/rules/sources/pdf/eots-v3.2-zh-rules-202402.pdf` 页码和规则编号标注。

## 顶层结构

《太阳帝国》是双人卡牌驱动兵棋。日本与盟军通过各自策略牌推动行动，地图状态、国家状态、美国政治意志和战略作战共同决定胜负。

一个常规游戏回合由以下阶段构成：

1. 战略阶段：增援、补员、战略作战、抽取策略牌。（规则 4.1，PDF 第 7 页）
2. 攻势阶段：确定主动权后，双方交替打牌并执行攻势或其他事件。（规则 4.2，PDF 第 7-8 页）
3. 政治阶段：处理国家状态与美国政治意志。（规则 4.3，PDF 第 8 页）
4. 耗损阶段：处理断补单位的耗损。（规则 4.4，PDF 第 8 页）
5. 回合结束阶段：完成回合收尾并推进回合。（规则 4.5，PDF 第 8 页）

## 攻势循环

攻势阶段是主要决策循环。当前攻势玩家通常选择：

- 将策略牌作为行动牌（OC）使用；
- 将策略牌作为事件牌（EC）使用；
- 使用 PASS；
- 在满足条件时使用未来攻势（FO）等特殊机制。

一次会移动单位并可能产生战斗的攻势，需要显式保存以下子步骤：

1. 选择攻势 HQ。
2. 根据牌值、HQ 效率与事件约束确定可启动单位数。
3. 选择并启动单位。
4. 执行攻势方移动。
5. 声明战斗格。
6. 确定情报条件。
7. 打开反应窗口并执行反应移动。
8. 结算海空战和可能的地面战。
9. 执行战后移动、控制权和攻势收尾。

这些步骤不能压缩成单次 `play_card()`，因为反应方会在中途获得合法决策权。（规则 7.0，PDF 第 16-19 页）

## 胜负与终止

全战役可能因日本无条件投降、盟军胜利条件、日本胜利条件或美国政治意志结果终止。引擎必须把“立即终止检查”和“阶段末终止检查”分开实现，不能只在回合结束统一检查。（规则 13.93、16.0，PDF 第 40-43 页）
